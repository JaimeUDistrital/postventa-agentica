## Decisiones
- Modo ANY: el modelo siempre responde con una función (herramienta o `responder_al_cliente`); texto sin functionCall → respaldo.
- Si hay tool_calls válidas y también `responder_al_cliente`, gana tool_calls (itera); el final solo se usa si no hay herramientas válidas.
- Args validados con `TOOL_SCHEMAS[tool].input`; en `ToolCall.args` van los args ya parseados (con defaults aplicados). Descartes → evento llm `status:"blocked"`, name `gemini.toolCallDescartada`, sin args (sin PII).
- El LLM recibe solo: `maskedMessage`, estado de sesión, contexto resumido (sin placa/ownerId/alias) y resultados de herramientas (se eliminan claves sensibles; la salida de `consultar_contexto_vehiculo` se omite porque trae placa).
- Errores: timeout (Promise.race + AbortController, `llmConfig.timeoutMs`) y `maxRetries`=1; el mensaje de error se trunca y se le quita la API key. Respuesta sin propuesta válida NO se reintenta.
- Tokens de pensamiento (`thoughtsTokenCount`) cuentan como salida para el costo.
- `gemini-3.6-flash`: 0,75/3,75 hasta 2026-12-31 y 1,50/7,50 desde 2027-01-01 (PLAN.md §2) según `now()`.
- Respaldo: devuelve `{...resultadoRespaldo, fallback:true, trace:[eventoLlmError, ...trazaDelRespaldo]}`.
